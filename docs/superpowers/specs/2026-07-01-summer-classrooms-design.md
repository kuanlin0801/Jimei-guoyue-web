# 暑訓專區「暑訓教室」表格 — 設計文件（Design Spec）

- **日期**：2026-07-01
- **狀態**：設計定稿，待進入實作
- **關聯**：在既有 `/summer`（暑訓專區）頁補上「各分部上課教室」一區。素材來源：`Reference/暑訓教室.jpg`（幹部提供的 115 年 7–8 月暑訓教室分配表）。

---

## 1. 背景與目標

幹部提供一張「115 年 7–8 月暑訓教室」表格圖（分部／教室／老師 ＋ 3 條注意事項）。需求是把它放上網站，且**排版好閱讀**。

主要受眾是家長／學生，多在**手機**上看。直接放整張表格圖，字會偏小、要點開放大、無法選取搜尋——不符「好閱讀」。故**重製為原生網頁表格**，用站上米色卡片風格呈現，手機上字清晰、免縮放。

`/summer` 頁已存在，且已有「暑訓行事曆」「練習作業」「作業繳交」三區，是此表格最自然的落點（同一暑訓脈絡、同一批受眾）。

---

## 2. 核心設計決策

| 項目 | 結論 | 說明 |
|---|---|---|
| 呈現方式 | **原生網頁表格**（非放原圖） | 手機好讀、可選取；經使用者確認 |
| 落點 | `/summer` 頁**第 2 區**（行事曆之後、練習作業之前） | 動線：何時（行事曆）→ 何處（教室）→ 練什麼（作業）→ 繳交 |
| 資料位置 | `src/data/summer.js` 新增 `classrooms` 物件 | 半靜態、每年暑假由幹部改，符低維護原則（與 assignments 一致） |
| 分部標籤 | **照原圖暑訓用語**（竹笛／二胡／揚打／國樂小藝星…） | 不改成關於我們頁的分部名（笛子／胡琴／揚琴打擊）——暑訓表是幹部針對暑訓自己標的 |
| 老師名 | **「陳珮珊」** | 古箏/大提琴老師；與站上師資頁一致（原圖亦為此） |
| 區段圓點色 | 行事曆(綠) → **教室(金)** → 練習作業(改為朱紅) | 維持全站「竹綠→金→朱紅」輪替；插入一區的連帶調整 |

---

## 3. 架構與檔案

| 檔案 | 類型 | 職責 |
|---|---|---|
| `src/data/summer.js` | 改 | 新增 `classrooms` 物件：`title`（副標）、`rows[]`（8 列 `{part, room, teacher}`）、`notes[]`（3 條） |
| `src/pages/summer.astro` | 改 | 行事曆區與練習作業區之間插入「暑訓教室」section（讀 `summer.classrooms` 渲染表格＋注意事項）；練習作業 `sec-dot` 由 `gold` 改 `seal`；新增表格樣式 |

> **無純邏輯**：本功能是靜態資料 ＋ 版面，`classrooms` 直接由 Astro 於 build 時渲染，Astro 會自動跳脫（無 XSS 疑慮）。不涉 `src/lib/`，故**不加 vitest**（與現有暑訓作業／行事曆做法一致）。

## 5. 顯示規格

- **區標題**：`<h2 class="sec-head"><span class="sec-dot gold"></span>暑訓教室</h2>`
- **副標**：`classrooms.title` 用頁面現有 `.sec-note` 樣式顯示於表格上方。
- **表格**：3 欄（分部／教室／老師）。
  - 表頭：竹綠（`--brand`）底、白字。
  - 列：柔線分隔（`--line-soft`），可加淡斑馬紋（偶數列 `--faint`/`--chip` 淡底）。
  - padding 寬鬆、字級 ≥14px，手機好點好讀。
- **注意事項**：表格下方 `<ul>`，每條一列小字（`--muted`），與表格同卡片內。
- **合奏時間**：`合奏` 那列的 `10:30–12:00` 以 `time` 欄位存放，渲染成分部欄內的小字副行（`.cr-time`），避免長字串把欄位撐寬。
- **手機**：cell 用 `white-space:nowrap`＋≤480px 縮小 padding／字級，讓 3 欄單行不換行、375px 下不需水平捲動；表格外層仍包 `overflow-x:auto` 作極窄裝置（<320px）保險。

## 6. 落點細節（`summer.astro`）

現況順序：`暑訓行事曆(brand)` → `練習作業(gold)` → `作業繳交(card)`。

插入後：
1. `暑訓行事曆`（`sec-dot brand`，不變）＋行事曆圖卡（不變）
2. **`暑訓教室`（`sec-dot gold`，新增）** ＋ 副標 ＋ 表格卡
3. `練習作業`（`sec-dot` 由 `gold` **改 `seal`**）＋作業卡（內容不變）
4. `作業繳交`（不變）

---

## 7. 驗收標準

- `npm run build` 無誤。
- 預覽：桌機／手機表格正確、8 列資料與原圖一致、3 條注意事項齊全。
- 手機（≤480px）表格不破版、字清晰、必要時可水平捲動。
- 區段圓點色為 綠→金→朱紅。
- 既有行事曆／作業／繳交三區行為與外觀不受影響。

## 8. 不做（YAGNI）

- 不放原始表格圖（改為原生表格；若日後要「看原圖」再議）。
- 不做每列可點開詳情、不做篩選／排序。
- 不動資料流（Calendar API／CSV／Apps Script）與 `src/lib/` 純邏輯。
- 不改關於我們頁的分部師資名稱（兩處用途不同，暑訓表照原圖標籤）。
