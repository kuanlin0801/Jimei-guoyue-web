# 文件下載接真實資料 — 操作 Checklist

> **目標**：讓「文件下載」頁顯示真實資料 —— 公告夾帶的附件 ＋ 常設文件試算表，取代目前的範例。
> **前置**：公告附件功能已隨上次 push 上線（公告頁能顯示 📎 附件、文件頁已是動態合併）。
> **對應**：`docs/superpowers/specs/2026-06-25-announcement-attachments-design.md`、`.../plans/2026-06-25-announcement-attachments.md`
> **角色標示**：👤 = 你（在 Google／Cloudflare 點選）；🛠️ = 工程端（我，負責驗證）

---

## A. 公告試算表加附件欄（👤）— 讓公告能附檔

- [ ] **A1** 開啟現有的**公告試算表**（已在用的那張）。
- [ ] **A2** 在現有四欄（日期／標題／內容／置頂）右邊，`E1`、`F1` 加兩個表頭：**附件名稱**、**附件連結**（順序不可換，程式照位置讀）。
- [ ] **A3** 要附檔的公告，在該列填：
  - **附件名稱**：例如 `成果發表會通知單.pdf`（帶副檔名 → 文件頁類型標籤會自動推成 PDF；不帶也可，會標「檔案」）
  - **附件連結**：該檔案的 **Google Drive 連結**
  - 沒有附件的公告：這兩欄**留空**即可（不影響）。
  - *提醒*：連結必須是 `http(s)://` 開頭，否則會被安全機制擋成「連結無效」。

---

## B. 建「文件試算表」（👤）— 放常設文件（樂譜、長期報名表等）

- [ ] **B1** Google 雲端硬碟 → 新增 Google 試算表，命名如「集美國樂－文件」。
- [ ] **B2** `A1`~`F1` 填**六欄**表頭：**日期、名稱、連結、類型、備註、置頂**。
- [ ] **B3** 點 **A 欄**整欄 → 格式 → 數值 → **純文字**（避免日期被自動轉型）。
- [ ] **B4** 每份常設文件一列：
  - **日期**：`2026-06-25` 格式（用於排序）
  - **名稱**：顯示名稱
  - **連結**：Google Drive 連結（`http(s)://`）
  - **類型**：自己填 `PDF`／`Excel`／`圖片`／`表單`… （這張表的類型是你填的）
  - **備註**：選填
  - **置頂**：要釘到最前面就填 `V`，否則留空

---

## C. 發布文件試算表 CSV（👤）

- [ ] **C1** 檔案 → 共用 → **發布到網路** → 選該工作表 → 格式 **CSV** → 發布 → 複製連結（結尾應為 `…&output=csv`）。

---

## D. 設定 Cloudflare 環境變數（👤）

- [ ] **D1** Cloudflare → 你的專案 → **Settings → Build → Variables and secrets**。
- [ ] **D2** 在 **build 變數區**（**不是** runtime）新增：名稱 `PUBLIC_DOCUMENTS_CSV`，值 = C1 的連結。
- [ ] **D3** 儲存。

---

## E. 重新部署（👤）

- [ ] **E1** GitHub Desktop 按 **Push**（或 Cloudflare 對最新部署按 **Retry／Redeploy**）。
- [ ] **E2** 等 Cloudflare 顯示 **Success**。

---

## F. 驗證（🛠️ 我來，你給我網址即可）

- [ ] **F1** 開 `https://jimei-guoyue-web.kuan-lin.workers.dev/documents`，確認顯示**真實的常設文件 ＋ 公告附件合併清單**（不再是「（範例）」那幾筆）。
- [ ] **F2** console 無 **CORS／fetch** 錯誤。
- [ ] **F3** 排序正確：**置頂最前、其餘依日期新到舊**。
- [ ] **F4** 公告附件那幾筆標「**來自○○公告**」、類型標籤合理。
- [ ] **F5** 點一份文件 → 正確在 Google Drive 開啟。
- [ ] **F6**（安全）刻意在文件表放一個非 `http(s)` 連結 → 該筆顯示「（連結無效）」、不可點 → 驗畢移除。

---

**完成後**：文件下載頁即接真實資料。日後維護方式 ——
- **公告附檔**：在公告試算表那列填 `附件連結`（自動同時出現在公告頁與文件頁）。
- **常設文件**：在文件試算表加一列；`置頂` 填 `V` 可釘最前。
- 兩者都有約 **5 分鐘** 的 Google published CSV 快取延遲。
